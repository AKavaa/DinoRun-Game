# 🦖 Dino Run Game
A Python-based endless runner game built with Tkinter where a dinosaur jumps over cactuses to survive as long as possible.

Dino Run is a simple yet addictive endless runner game inspired by the Chrome offline dinosaur game. 
It is built entirely with Python's Tkinter library — no external game frameworks used.

The player controls a dinosaur that must jump over incoming cactuses. The game speeds up over time, 
making it increasingly challenging. Your goal: survive as long as you can and beat your high score!

- ✅ Endless gameplay with increasing difficulty
- ✅ Simple controls (Spacebar to jump)
- ✅ Score tracking system
- ✅ Collision detection
- ✅ Random cactus generation
- ✅ Lightweight — runs on any machine with Python
